# Cricket Board Scorer

A Java-based application for scoring and managing cricket matches. This project is built as a semester project for an Object-Oriented Programming (OOP) course.

## 📋 Overview

Cricket Board Scorer is a comprehensive application designed to track, manage, and display cricket match scores in real-time. It provides an intuitive interface for scorekeeping and match management with support for multiple match formats.

## 🏗️ Project Structure

```
Cricket-Board-Scorer/
├── src/              # Source code files
├── bin/              # Compiled binaries and output
├── lib/              # External libraries and dependencies
├── database_code/    # Database-related code and scripts
└── README.md         # Project documentation
```

## 🎯 Features

- **Real-time Score Tracking**: Update and display cricket match scores in real-time
- **Match Management**: Create, manage, and track multiple cricket matches
- **Player Statistics**: Record and manage player information and statistics
- **Database Integration**: Persistent storage of match data and player records
- **OOP Design**: Built with Object-Oriented Programming principles

## 💻 Technology Stack

- **Language**: Java
- **Architecture**: Object-Oriented Programming

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- A Java IDE (Eclipse, IntelliJ IDEA, NetBeans, or VS Code with Java extensions)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/meer140/Cricket-Board-Scorer.git
   cd Cricket-Board-Scorer
   ```

2. Compile the source code:
   ```bash
   javac -d bin src/*.java
   ```

3. Run the application:
   ```bash
   java -cp bin MainClass
   ```

## 📦 Directories

- **`src/`** - Contains all Java source files for the application
- **`bin/`** - Contains compiled `.class` files and executable binaries
- **`lib/`** - External libraries and JAR files (if any)
- **`database_code/`** - Database schema, queries, and related code
